# Oumra Prestige — Site vitrine

Description
-
Site vitrine statique pour une agence proposant des voyages spirituels (Oumra) vers La Mecque. Contient des pages HTML, du CSS et un dossier d'images.

Structure (fichiers principaux)
-
- [index.html](index.html) — Accueil
- [a_propos.html](a_propos.html) — À propos
- [conexion.html](conexion.html) — Connexion
- [s-inscrir.html](s-inscrir.html) — Inscription
- [reserv.html](reserv.html) — Réservation
- [conta.html](conta.html) — Contact
- [css/style.css](css/style.css) — Feuille de style principale
- [image/](image/) — Images utilisées par le site

Technologies
-
- HTML5
- CSS + Bootstrap 5 (CDN)
- Font Awesome / Bootstrap Icons (CDN)

Utilisation
-
1. Copier le dossier du projet sur votre machine.
2. Ouvrir `index.html` dans un navigateur (site statique — aucun serveur requis).

Recommandations rapides
-
- Vérifier que toutes les pages ont `lang="fr"` (contenu en français).
- Ajouter une `meta description` à chaque page pour le SEO.
- Confirmer le type du favicon (`image/jpeg` ou convertir en PNG) et son chemin.
- Préférer `css/style.css` comme nom clair pour la feuille de styles.
- Remplacer les `href="#"` par des liens réels ou ajouter `aria-label`/`role` pour l'accessibilité.
- Éviter `background-attachment: fixed` sur mobile (problèmes de performance).
